# ETF Decision Support System

A web-based Decision Support System for ETF selection using data analysis and machine learning.

## Objectives

- Analyze historical ETF data
- Perform exploratory data analysis
- Perform technical analysis
- Build and evaluate machine learning models
- Compare ETF performance
- Provide decision-support recommendations

## Technology Stack

- Frontend: React + TypeScript + Vite
- Backend: FastAPI
- Database: PostgreSQL
- Data Analysis: Pandas, NumPy
- Machine Learning: Scikit-learn, XGBoost
- Visualization: Recharts
- Containerization: Docker
- Version Control: Git + GitHub
